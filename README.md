## 📖 Executive Summary

The **Java OOP Systems Laboratory** is a foundational computer science coursework portfolio developed at **Alliance University**. Demonstrating core object-oriented programming paradigms, this repository features modular Java classes exploring state encapsulation, geometric entity modeling, conditional comparison algorithms, and parameterized method invocation through clean JVM bytecode compilation.

---

## 🧩 Laboratory Modules & Problem Solutions

| Class File | Object-Oriented Concepts | Mathematical / Algorithmic Focus |
| :--- | :--- | :--- |
| `Rectangle.java` | Class modeling, field encapsulation, private state, getters/setters | Area ($l \times w$) and perimeter ($2(l + w)$) geometric calculations |
| `Biggest.java` | Conditional branching, ternary logic, comparison functions | Algorithmic resolution of numerical maximum across integer values |
| `Message.java` | Parameterized methods, string formatting, console output streams | Dynamic console notification generation |
| `Main.java` | Application driver, object instantiation, method dispatch | Orchestrates objects and coordinates runtime execution |

---

## ✨ Core OOP Concepts Explored

- **🔒 Data Encapsulation:** Guarding internal class attributes using private access modifiers while exposing controlled mutating and accessor methods.
- **📐 Mathematical Modeling:** Creating software abstractions representing geometric shapes with calculated properties.
- **⚡ Conditional Efficiency:** Optimizing decision branching for multi-variable comparisons.

## ⚙️ Compilation & Execution

### 1. Clone the Repository
```bash
git clone https://github.com/keerthi19hub/Java_Assignment.git
cd Java_Assignment
```

### 2. Compile Java Classes
```bash
javac *.java
```

### 3. Run the Main Application
```bash
java Main
```
