## 1. Overview & Contents

This repository contains academic Java laboratory exercises developed to master core Object-Oriented Programming (OOP) concepts:

| File | Concepts Demonstrated |
| :--- | :--- |
| `Rectangle.java` | Class modeling, field encapsulation, getter/setter methods, and area/perimeter calculations |
| `Biggest.java` | Conditional logic, numerical comparison algorithms, and ternary evaluation |
| `Message.java` | Method parameterization, string formatting, and console output streams |
| `Main.java` | Driver class instantiating objects and executing method routines |

---

## 2. Compilation & Execution

```bash
# Compile all files
javac *.java

# Execute main driver
java Main
```
